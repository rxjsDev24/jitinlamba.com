# jitinlamba.com

Personal portfolio of Jitin Lamba. Next.js (App Router), strict TypeScript, Tailwind CSS v4, deployed on Vercel.

Design and decisions live in [ARCHITECTURE.md](ARCHITECTURE.md).

## Develop

```bash
nvm use
pnpm install
pnpm dev
```

## Checks

```bash
pnpm lint && pnpm typecheck && pnpm format:check && pnpm build
```
